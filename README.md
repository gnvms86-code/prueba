# prueba

Repositorio de prueba inicializado para verificar que la conexión con GitHub funciona correctamente.

## Estructura

- `README.md`: este archivo.
- `.gitignore`: archivos y carpetas que Git debe ignorar.

## Primeros pasos

```bash
git clone https://github.com/gnvms86-code/prueba.git
cd prueba
```

A partir de aquí puedes añadir tu código y hacer commits con normalidad:

```bash
git add .
git commit -m "describe tu cambio"
git push origin main
```
